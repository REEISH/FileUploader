# File Uploader App

A lightweight, cloud-based file storage application inspired by Google Drive. This application allows users to securely upload, organize, and download their files with full support for nested folders and directory structures. Designed for resource-constrained environments, the application enforces a strict 16 MB storage quota per user.

## Features

* **File Management:** Upload and download files of various formats securely.
* **Directory Structure:** Create folders, navigate through directories, and organize files hierarchically, just like a native file system.
* **Storage Quotas:** Strict 16 MB maximum storage limit per user to ensure optimized, low-cost server operation.
* **User Authentication:** Secure registration and login to keep user files private and separate from others.
* **Storage Tracking:** Real-time calculation of used storage against the 16 MB cap.
